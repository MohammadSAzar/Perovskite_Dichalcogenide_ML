# Identifier Philosophy

## 1. Core Principle

An identifier must represent exactly one conceptual entity.

Chemical formula equality does not imply material identity.

For example, `CaTiO3` may refer to:

- a normalized chemical composition;
- one MP database record;
- another MP polymorph;
- one CMR record;
- one experimental sample;
- one PSK-TMD heterostructure sample;
- one mapping between literature and computational records.

These entities must have different identifiers.
