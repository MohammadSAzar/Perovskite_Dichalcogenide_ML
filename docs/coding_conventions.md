# Coding Conventions

## 1. General Principles

- Prefer clear and readable code over clever code.
- Keep scientific logic explicit.
- Avoid unnecessary abstraction.
- Reuse shared logic instead of duplicating it.
- Preserve data provenance whenever data are transformed.
- Do not silently discard ambiguous or invalid scientific records.
