# PSK-TMD-ML
Computational research pipeline for the PhD project:

**Design and Synthesis of Perovskite–Dichalcogenide Heterostructures
for Photocatalytic Water Splitting via a Machine Learning Approach**


## Scope
This repository contains three connected computational pipelines:

1. Literature corpus processing and Gold Dataset preparation
2. MP/CMR feature database preparation and Gold-to-MP/CMR mapping
3. Machine-learning modeling and virtual screening


## Material terminology
- PSK: oxide perovskite
- TMD: transition metal dichalcogenide


## Project status
Current phase: Phase 0 — Project infrastructure.
